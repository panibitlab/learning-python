* <if-elif-else> *

if condition1:
    statement a
elif condition2:
    statement b
elif condition 3:
    ...
else:
    statement c

> if condition1 is true, condition2 and condition3 are not checked.
> if none of conditions are true, statement c is done nonetheless.

for i in iterable:
    statement 1

for i in iterable:

    break

> it can continue by reaching a specific goal and do statement 2:

for i in iterable:
    statement 1
    continue

> loops can be nested:

for i in iterable:
    for j in iterable:
        statement 1

> for i in range(start, stop (+1), step):

* <list> *

a = []
> a = [index_1, index_2, ...., index_n]
> a = list( <AnyOtherTypeOfDataStructure> )

list("string") = ['s', 't', 'r', 'i', 'n', 'g']

> len(a) = number of indexes in a
> a [start : stop (up to, but not including) : step] for slicing.

* in list a = [1, 2.5, 'a', [4, 'hi'], 5, 'b'] return 'hi':
  [4, 'hi'] is the 4th element. a[4] returns [4, 'hi'] and 'hi' is the last element in this list.
  a[4][-1] returns 'hi'.
  * return 'h' in 'hi': a[4][-1][0]

> for i in a:
    print(i)
    ----------> prints elements of the list.

  for i in range(len(a)):
    print(i)
    ----------> prints the indexes.

  for i in range(len(a)):
    print(a[i])
    ----------> prints elements of the list.

> a.append(<value>) for adding a new element to the END of the list.
> a.insert(<index>, <value>) for adding a new element in position of the given INDEX.
> a.extend(iterable) for extending the list, using an iterable data structure (equal to a-list + b-list).

* a = [1, 2, 3]:
  a.append([4,5,6])
  -----------------> a = [1, 2, 3, [4, 5, 6]]
  a.extend([4, 5, 6])
  -----------------> a = [1, 2, 3, 4, 5, 6]

> a.remove(<value>) removes the first item from the list whose value is equal to <value>.
> a.pop(<position>) removes the item at the given position in the list AND returns it.
  * if no index is specified, last item in the list is removed and returned.
> a.clear() clears list.
> a.index(<value>) returns the index of the given value.
> a. count(<value>) returns the number of times, given value appears in the list.
> a.sort() sorts a from lowest to greatest.
> a.reverse() reverses the elements of the list.
> a.copy()

* <dictionary> *

*it has <key:value> structure.

> d = dict(<key:value>)
  d = {<key:value>}
> d[<key>] returns the value of that key.
> d.keys() returns keys in dictionary. *usually comes in list(d.keys())
> d.values() returns values in dictionary. *usually comes in list(d.values())
> d[<key>] = <value> for setting a value for a key.
> list(d) returns a list of all the keys used in the dictionary d.
> len(d) returns the number of items in the dictionary d.
> del d[<key>] for deleting a key:value pair.
> <key> in d or <key> not in d, to check availability of a key in d.
> d.clear()
> d.get(<key>) returns the value of the given key. (equal to d[<key>])
> d.pop(<key>) removes the key:value by the key given AND returns its value.
> d.popitem(<key>) removes the key:value by the key given AND returns the pair.
> d.setdefault(<key> , <value>) it returns the actual value of key IF IT EXIST, if not, it returns the value given.

> for i in d:
      print(i)
      -------> prints keys.
 
 for i in d:
      print(d[i])
      -------> prints values.
 
 for i in d:
      print(i, d[i])
      -------> prints <key:value>
 
 for i, j in d.items():
      print(i, j)
      -------> prints <key:value>

t = () equal to tuple(<ExampleOfDataStructure>): for one element (<element1> , )
