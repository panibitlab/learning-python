* <dictionary> *

*it has <key:value> structure.

> d = dict(<key:value>)
  d = {<key:value>}
> d[<key>] returns the value of that key.
> d.keys() returns keys in dictionary. *usually comes in list(d.keys())
> d.values() returns values in dictionary. *usually comes in list(d.values())
> d[<key>] = <value> for setting a value for a key.
> list(d) returns a list of all the keys used in the dictionary d.
> len(d) returns the number of items in the dictionary d.
> del d[<key>] for deleting a key:value pair.
> <key> in d or <key> not in d, to check availability of a key in d.
> d.clear()
> d.get(<key>) returns the value of the given key. (equal to d[<key>])
> d.pop(<key>) removes the key:value by the key given AND returns its value.
> d.popitem(<key>) removes the key:value by the key given AND returns the pair.
> d.setdefault(<key> , <value>) it returns the actual value of key IF IT EXIST, if not, it returns the value given.

> for i in d:
      print(i)
      -------> prints keys.
 
 for i in d:
      print(d[i])
      -------> prints values.
 
 for i in d:
      print(i, d[i])
      -------> prints <key:value>
 
 for i, j in d.items():
      print(i, j)
      -------> prints <key:value>

* <generator> *

> uses `yield` to produce values one at a time instead of returning all results at once.
> def gen():
    yield 1
    yield n

    for execution:

    for i in gen():
    print(i)

> ex) generating even numbers:
      def even_numbers(n):
          for i in range(n):
            if i % 2 == 0:
                yield i
      execution:
      for num in even_numbers(10):
          print(num)
          -----------------------> prints even numbers from 0 to 8. (range(n) = up to n, but not including n)

> *generator expression: (<expression> for <condition>)
  ex) (i for i in a if i % 2 == 0) prints even numbers that were in the given list.

> ABSTRACTION:
  an abstract class defines a common blueprint for other classes and cannot be instantiated.
  it requires its subclasses to implement specific methods.

> POLYMORPHISM:
  allows different objects (from different classes) to respond to the same method call in their own specific way.

> ENCAPSULATION:
  the principle of hiding internal data and exposing only controlled access through methods.

  ex) class BankAccount:
          def __init__(self, balance):
            self.__balance = balance   # private variable

          def deposit(self, amount):
            if amount > 0:
               self.__balance += amount

          def get_balance(self):
               return self.__balance
